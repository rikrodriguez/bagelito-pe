QA one-shot Culqi event lookup diagnostic. This script is conditionally invoked AFTER next build only when the system commit message exactly equals `qa: one-shot readonly Culqi event diagnostics` and the full QA preview branch, project, URL, sandbox mode and secret-key prefix match. It reads one limited event-list page (2026-10-21–24) and up to two authenticated GET requests for a validated event tied to synthetic order BAG-000013. No charge POST, no webhook send, no Supabase writes, no PII/event IDs/secret values in build logs. It intentionally cannot mark orders paid or acknowledge any webhook. It never fails the build; inspect `culqi_qa_readonly_event_diagnostic` log for sanitized categories. An empty bounded page does not prove Culqi generated no events. After diagnostic, remove the build hook from the QA branch. Never merge the diagnostic or temporary permission into production.
