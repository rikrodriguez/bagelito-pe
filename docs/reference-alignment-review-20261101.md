These are **reference-guided conceptual layers**, not independent product/venue photographs; generated staff do not represent verified real employees. New layers have no rasterized UI or product-price labels. Text and interactive controls are DOM/SVG. Mobile SVG views reuse only the newly generated counter art. Encoding preserves all RGBA pixels of each selected current PNG; that is an encoding claim, not a claim of unchanged pixels outside the generative edit regions.

The already-read specialized `website-builder/references/design-taste-frontend.md` and `image-to-code.md` were applied through measured hierarchy, spatial/material matching, literal reference anchors and comparative screenshots. Their generic defaults do not override the supplied Bagelito identity or the user-retired copy. Native typography, existing dependencies and the approved commercial flow are preserved; no Figma workflow, hosted builder, paid generation tool or new dependency was used.
