# Bagelito Commerce — TanStack Start technical preview

**Status:** AI Studio-targeted source scaffold, NOT an AI Studio deployment. Created 2026-10-27. The original Next.js production app stays unchanged at https://bagelito.pe/.

## Purpose

This directory provides a standalone TanStack Start source tree, using the documented TanStack conventions (`vite.config.ts`, `src/router.tsx`, `src/routes/__root.tsx`, `src/routes/index.tsx`, `server.handlers` for REST). It is intended to be merged into the **private repo generated by AI Studio** for the Bagelito sub-account. Do not point AI Studio Git Sync to the existing Next.js repository and do not overwrite its generated baseline.

## Functional scope in source

- Product gallery: eight regular bagel flavors and real existing website image URLs.
- Pack configurator: Grande / Mini, quantity, mixed/single flavors, two-flavor quantity.
- 2-bagel + schmear combo preview (**price remains unapproved; checkout blocked**).
- Standalone schmear configurator with 120/180/240g menu reference prices.
- `GET /api/catalog`: source-verified published menu only.
- `GET /api/batch`: read-only Supabase adapter using server-only environment credentials. It fails closed (503) if unconfigured or degraded.
- Portable read-side domain functions preserving source order-capacity and expired Culqi hold semantics.
- Responsive CSS & mobile layout.

**No purchase, charge, order creation, dashboard, account authentication, CRM write, or live WhatsApp/email operation exists in this pilot.**

## Local run — external network and installed dependencies required

```bash
cd migration/ai-studio/tanstack-app
npm install
npm run dev
npm run build
npm run typecheck
```

TanStack Start generates `src/routeTree.gen.ts` automatically; do not hand-author it. This code was not compiled against TanStack packages in this session because the npm registry isn't accessible inside the execution container. The **framework-free** domain modules and tests were compiled and executed independently; see parent `VALIDATION_2026-10-27.md`.

## Secrets (server only)

Configure `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in **AI Studio Project Settings → Secrets**. Do not commit real secrets. The server adapter also accepts the existing `NEXT_PUBLIC_SUPABASE_URL` as a transitional fallback for the public URL only.

The service-role secret must never be sent to the client. The `src/server/batch.server.ts` module is intended exclusively for the TanStack server route.

## Production safety

- GHL CRM must never become the source of truth for stock or payment.
- The current product catalog is a published October reference, **not approved live inventory or pricing**.
- Mini flavor applicability, premium inclusion/surcharge, the two-bagel combo price and batch cadence are not conclusively specified; checkout must remain disabled.
- A browser quote, redirect, or front-end flag can never confirm a payment or reserve capacity.
- The transactional reservation RPC and Culqi sandbox must be ported/tested separately before any production cutover.
- Existing image URLs are temporary dependencies on bagelito.pe; migrate actual image assets to the AI Studio project's public folder before shipping.
